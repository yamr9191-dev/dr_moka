محتويات المجلد:
1. index.html      -> واجهة التطبيق والوظائف الكاملة
2. manifest.json   -> إعدادات تثبيت التطبيق على الموبايل (PWA)
3. sw.js           -> Service Worker للعمل بدون إنترنت (Offline)
4. icon.svg        -> أيقونة التطبيق عالية الدقة (Vector)
5. icon-192.png    -> أيقونة أندرويد 192x192
6. icon-512.png    -> أيقونة أندرويد 512x512
7. README.txt      -> دليل التشغيل والتثبيت

-----------------------------------------------------------------
طريقة التشغيل والتثبيت كتطبيق حقيقي على الأندرويد (PWA):
-----------------------------------------------------------------
1. ارفع جميع الملفات الموجودة داخل هذا المجلد على استضافة تدعم HTTPS
   مثل: GitHub Pages أو Netlify أو Vercel.
2. افتح رابط الموقع من متصفح Google Chrome على هاتف الأندرويد.
3. اضغط على القائمة (الثلاث نقاط في الأعلى) ثم اختر:
   "تثبيت التطبيق" (Install App) أو "الإضافة إلى الشاشة الرئيسية".
4. سيظهر التطبيق بأيقونته المخصصة (تاج وحرف M) على شاشة الموبايل
   ويعمل في وضع ملء الشاشة (Standalone) وبدون إنترنت بالكامل!
